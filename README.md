# Bug 收容所 · 1024 特别版

把事故变成卡牌，把复盘变成图鉴。一个纯前端的「Bug 收容 / 复盘 / 图鉴 / 分享」小应用，为 1024 程序员节而造。

![技术栈](https://img.shields.io/badge/React%2018-Vite%205-TypeScript-39ff88)

## 启动与构建

```bash
npm install        # 安装依赖
npm run dev        # 本地开发，默认 http://localhost:5173
npm run build      # 类型检查 + 生产构建，产物在 dist/
npm run preview    # 本地预览生产构建，默认 http://localhost:4173
```

> 若默认端口被其他项目占用（如 5173 / 4173 已被占用），可指定端口启动：
> `npm run dev -- --port 5199` 或 `npm run preview -- --port 4180 --strictPort`

## 功能说明

### 收容台
- **示例一键填表**：内置 16 个示例（覆盖全部 6 种栖息地与各稀有度），点击自动填表，可修改后再收容。
- **开卡动效**：点击收容后播放约 1 秒的翻转 + 稀有度光爆动画，指南区随后淡入。
- **表单字段**：Bug 名称（必填）、技术栈多选 chips、栖息地、危险指数 / 复现难度 / 影响范围（1-5）、是否线上、症状关键词与补充描述（可选）。
- **卡牌生成**：稀有度、编号（`BUG-1024-XXXX` 递增）、战力评分、驯服难度、随机吐槽文案（生成后固定保存）。
- **评分透明**：卡牌上直接标注评分公式，如 `危险 5×12 + 影响 5×10 + 复现 5×6 + 线上 +10 + 玄学 +8 = 158 → SSR`。
- **驯服指南**：栖息地专属排查建议 + 通用三步（最小化复现路径 → 对比最近变更与日志 → 准备回滚与监控）。
- **根因归类 + 防御建议**：按关键词自动归类（空指针 / 并发 / 缓存 / 时区 / CSS / 依赖 / 网络 / 数据 / 内存泄漏 / 配置 / 误操作），并给出一条可复用的规避措施。
- **复盘三问 + 预防疫苗**（按栖息地生成 2-3 条）。
- **操作**：导出图片（移动端唤起系统分享）、复制复盘模板、复制分享链接、编辑这张卡、再收容一只；生成后自动保存到图鉴。
- **同名去重**：同名卡牌不重复入库，重复收容会替换旧卡。

### 我的图鉴
- 统计即筛选：总收容数 / SSR / SR / R / N / 今日收容 六张统计卡，点击即筛选，选中时亮起稀有度同色霓虹边框与流光。
- 收集进度条：稀有度分布彩色分段展示。
- 导出复盘：一键生成结构化 Markdown（概览 + 按日期 + 按技术栈 + 含复盘三问的明细），支持下载或复制进周报。
- 卡片按时间倒序；详情弹窗支持导出图片、编辑重收容（编号与收容时间不变）、删除单卡。
- 清空图鉴需二次确认，清空后自动恢复一套默认示例卡；图鉴被清空后重新打开也会自动补样。
- 默认示例 9 张，覆盖全部栖息地与 SSR/SR/R/N。

### 分享
- **分享卡 PNG**：1080×1440 分享卡含标题、卡牌、评分公式、驯服指南、根因归类与防御建议、预防疫苗与引流页脚；`html-to-image` 导出（8 秒超时自动降级 Canvas 绘制）；移动端通过 `navigator.share` 唤起系统分享，桌面端直接下载 `bug-card-{卡牌编号}.png`。图鉴网格悬停即可对任意卡牌导出。
- **分享链接（无后端）**：卡牌精简数据 → JSON → `encodeURIComponent` → `btoa` → 写入 URL hash（`#bug=...`）。新标签打开显示「你收到一只 Bug」只读卡牌，可一键收容；解析失败提示「分享链接无效或已损坏」。

### 稀有度算法

```
score = danger×12 + scope×10 + reproduce×6 + (线上 ? 10 : 0) + (栖息地为玄学 ? 8 : 0)
score ≥ 120 → SSR；≥ 95 → SR；≥ 65 → R；否则 N
驯服难度 = min(5, ceil((danger + reproduce) / 2))
```

## 数据存储方式

- **数据存于浏览器 localStorage**（key：`bug-shelter-1024-cards`），各用户、各浏览器独立，不上传任何服务器，**无后端、无登录、无外部 AI API**。
- 分享通过链接 / PNG 完成：链接里只包含必要字段（不含 id / createdAt / cardNo），接收方收容时重新生成编号。
- 隐私优先：不要求上传代码或日志，表单全程提示请勿粘贴真实密钥、完整代码或敏感日志。

## 目录结构

```
src/
  App.tsx                 # 应用入口、状态与数据流
  types.ts                # BugCard / BugDraft / SharedBug 数据模型
  lib/
    rarity.ts             # 评分、稀有度、驯服难度算法
    templates.ts          # 吐槽文案、排查步骤、复盘三问、预防疫苗模板
    card.ts               # 卡牌构建 / 编号生成 / 分享数据还原
    storage.ts            # localStorage 读写与首次示例卡注入
    share.ts              # 分享链接编码与解析（#bug=...）
    review.ts             # 复盘模板文本生成
    exportImage.ts        # html-to-image 导出 + Canvas 兜底
  components/
    Header.tsx            # 标题、隐私提示、Tab 导航
    ShelterTab.tsx        # 收容台（表单 + 结果区）
    BugCardArt.tsx        # 卡牌视觉组件
    ShareCard.tsx         # 1080×1440 隐藏分享卡
    CodexTab.tsx          # 我的图鉴（统计 / 筛选 / 详情 / 删除）
    IncomingCard.tsx      # 「你收到一只 Bug」只读收容区
```
